# TDD Plan: TV.png Image-Based Frame

## Problem Statement

The CRT TV frame is currently drawn entirely with CSS (wood grain gradients, chrome trim,
speaker grille, dark panel). The user provided a Copilot-generated `TV.png` image — a
photorealistic 1980s console TV with a bright green chroma-key screen. We need to replace
the CSS-drawn cabinet with this image, positioning our rendered content (neon backdrop,
avatar, broadcast text, overlays) inside the green screen area.

## Image Analysis

- **Dimensions:** 1024 × 1024 px
- **Background:** ~38% transparent (TV shape floats on any background)
- **Green screen bounds (percentage):**
  - Left: 13.7%, Top: 24.4%
  - Width: 57.3%, Height: 46.8%
- **Green center color:** RGBA(43, 196, 2, 255)
- **Right panel:** Contains speaker grille, channel knob, power switch (all visual in image)

## Architecture Change

**Before:** `CrtFrame` renders CSS-drawn `.crt-bezel` (wood grain) → `.crt-screen` (flex) + `.crt-panel` (flex) + `.speaker-grille`

**After:** `CrtFrame` renders `<img src="/TV.png">` + absolutely positioned `.crt-screen` over the green area. Panel knobs become invisible hotspot overlays on the image's visual controls.

## Proposed Tests

### RED 1: CrtFrame should render the TV frame image
- **Assert:** An `<img>` with `data-testid="crt-frame-image"` and `alt="Retro CRT Television"` exists.
- **Expected failure:** No `<img>` element in current CrtFrame.

### RED 2: Speaker grille should NOT be a separate DOM element
- **Modify existing test** "should render a speaker grille in the panel"
- **Assert:** `queryByTestId('speaker-grille')` returns null (image provides the visual).
- **Expected failure:** Speaker grille element still exists in current code.

## Proposed Fix (GREEN)

1. **CrtFrame.tsx:** Add `<img src="/TV.png" className="crt-frame-image" data-testid="crt-frame-image" alt="Retro CRT Television" draggable={false} />`. Remove speaker grille div.
2. **App.css:** Replace `.crt-bezel` wood grain with image-based layout (position: relative, image fills container). Reposition `.crt-screen` absolutely at green-screen coordinates. Reposition `.crt-panel` as overlay on image's control area. Remove speaker grille CSS.
