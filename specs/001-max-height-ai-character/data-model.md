# Data Model: Max Height AI Character

**Feature**: 001-max-height-ai-character
**Date**: 2026-04-19
**Source**: `specs/001-max-height-ai-character/spec.md` §Key Entities + §Requirements

---

## Entities

### Visitor

A person interacting with Max. Identified by a guest Cognito identity and a locally-generated actor ID.

| Field | Type | Constraints | Notes |
|-------|------|-------------|-------|
| `actorId` | string (UUID) | Required, unique per browser | Generated on first visit, stored in localStorage |
| `cognitoIdentityId` | string | Auto-assigned by Cognito | Temporary guest identity for AWS credential scoping |
| `displayAlias` | string \| null | Optional, max 50 chars | Optional name/alias entered on first visit |
| `firstSeenAt` | ISO 8601 timestamp | Immutable after creation | First TV-on gesture |
| `lastSeenAt` | ISO 8601 timestamp | Updated each session | Used for memory retention window |
| `greetingHistory` | string[] | Max 20 entries | Last N greeting IDs to enforce no-repeat-within-3 |
| `rateLimitCounters` | RateLimitState | See below | Per-visitor rate limit tracking |

**Storage**: `actorId`, `displayAlias`, `greetingHistory` in browser localStorage. `cognitoIdentityId` managed by AWS SDK. Rate limit counters in localStorage with server-side enforcement via session metadata.

### Session

A single conversation between Max and a visitor. Capped at 50 turns or 20,000 tokens (whichever first), or 30 minutes.

| Field | Type | Constraints | Notes |
|-------|------|-------------|-------|
| `sessionId` | string (UUID) | Required, unique | Generated per TV-on gesture |
| `actorId` | string (UUID) | Required, FK → Visitor | Links session to visitor |
| `agentCoreSessionId` | string | Required | AgentCore Runtime session header for WebSocket continuity |
| `startedAt` | ISO 8601 timestamp | Immutable | TV-on gesture timestamp |
| `endedAt` | ISO 8601 timestamp \| null | Set on session close | Null while active |
| `turnCount` | integer | 0–50 | Incremented per visitor message |
| `tokenCount` | integer | 0–20,000 | Tracked from agent response metadata |
| `state` | SessionState enum | Required | See state transitions below |
| `greetingId` | string | Required | Which pre-generated greeting was used |
| `idleNudgeDelivered` | boolean | Default false | True after the one permitted idle nudge |

**Storage**: Server-side in AgentCore Memory (short-term events). Client-side shadow in Zustand `connection` store for UI state.

**State transitions**:

```
INITIALIZING → GREETING → ACTIVE → ENDED
                                  ↗
INITIALIZING → ERROR (cold start failure)
ACTIVE → BUDGET_CAPPED (hard-stop at $10)
ACTIVE → RATE_LIMITED (60/hr or 500/day breach)
ACTIVE → SIGNAL_LOST (backend unavailable after retry)
SIGNAL_LOST → ACTIVE (manual retry succeeds)
```

### SessionState (enum)

| Value | Description |
|-------|-------------|
| `INITIALIZING` | Agent booting, "buffering" UX shown |
| `GREETING` | Pre-generated greeting playing, LLM booting in background |
| `ACTIVE` | Normal conversation in progress |
| `ENDED` | Session cap reached (50 turns / 20K tokens / 30 min), in-character sign-off |
| `BUDGET_CAPPED` | $10 hard-stop triggered, "taking a break" state |
| `RATE_LIMITED` | Rate limit breached, in-character refusal |
| `SIGNAL_LOST` | Backend unavailable after silent retry, in-character error |
| `ERROR` | Unrecoverable error |

### Memory

What Max "remembers" about a visitor across sessions. Stored in AgentCore Memory with 30-day rolling retention.

| Field | Type | Constraints | Notes |
|-------|------|-------------|-------|
| `memoryId` | string | Auto-generated by AgentCore | Internal memory record ID |
| `actorId` | string (UUID) | Required, FK → Visitor | Memory namespace partition |
| `type` | MemoryType enum | Required | Category of memory |
| `content` | string | Max 500 chars | The remembered fact/preference/summary |
| `sourceSessionId` | string | Required | Which session produced this memory |
| `extractedAt` | ISO 8601 timestamp | Auto-set | When AgentCore extracted the memory |
| `expiresAt` | ISO 8601 timestamp | 30 days from `lastSeenAt` | Rolling retention; reset on each visit |

**Storage**: AgentCore Memory (semantic + summary + user preferences strategies). Namespace: `/max-height/{actorId}/`.

### MemoryType (enum)

| Value | Description |
|-------|-------------|
| `FACT` | A specific fact Max learned ("visitor likes sci-fi movies") |
| `PREFERENCE` | A visitor preference ("prefers morning conversations") |
| `SUMMARY` | Compressed conversation summary from a prior session |
| `TOPIC` | A topic discussed in depth ("talked about the 80s") |

### RateLimitState

Per-visitor rate limit tracking. Enforced client-side (optimistic) with server-side validation.

| Field | Type | Constraints | Notes |
|-------|------|-------------|-------|
| `hourlyCount` | integer | 0–60 | Messages in current hour window |
| `hourlyWindowStart` | ISO 8601 timestamp | Rolling | Resets each hour |
| `dailyCount` | integer | 0–500 | Messages in current day window |
| `dailyWindowStart` | ISO 8601 timestamp | Rolling | Resets each day (UTC midnight) |

**Storage**: localStorage (client-side) with server-side shadow via session metadata.

### Greeting

A pre-generated greeting from the pool. Immutable static assets deployed with the frontend.

| Field | Type | Constraints | Notes |
|-------|------|-------------|-------|
| `id` | string | Required, unique | e.g., `greeting-001` |
| `archetype` | GreetingArchetype enum | Required | One of the 8 bible §5 archetypes |
| `text` | string | 40–100 words | Max's greeting text |
| `audioPath` | string (relative URL) | Required | Path to pre-synthesized MP3 |
| `audioDurationMs` | integer | Required | Playback duration for LLM boot timing |
| `weight` | float | 0.0–1.0, default 1.0 | Selection probability weight |
| `tags` | string[] | Optional | Metadata for filtering (time-of-day, visitor-type) |

**Storage**: `/public/greetings/manifest.json` + `/public/greetings/audio/*.mp3`

### GreetingArchetype (enum)

Per personality bible §5:

| Value | Description |
|-------|-------------|
| `TV_PRESENTER_INTRO` | Classic "Welcome to the show" opening |
| `MID_MONOLOGUE` | Max is already mid-rant when visitor arrives |
| `MOCK_ANNOYANCE` | "Oh, you again..." (even for first-timers) |
| `SPONSOR_BREAK` | Fake commercial break intro |
| `TIME_OF_DAY_RIFF` | Commentary on morning/afternoon/evening |
| `SELF_CONGRATULATION` | Max celebrating his own brilliance |
| `FAKE_NEWS_FLASH` | "BREAKING NEWS — someone showed up!" |
| `GLITCH_COLD_OPEN` | Max "rebooting" mid-sentence |

## Relationships

```
Visitor 1──* Session       (one visitor has many sessions)
Session  1──* Memory        (one session produces many memories via async extraction)
Visitor  1──* Memory        (one visitor has many memories across sessions, namespaced)
Session  1──1 Greeting      (each session uses exactly one greeting)
```

## Validation Rules

| Entity | Rule | Source |
|--------|------|--------|
| Session | `turnCount` ≤ 50 OR `tokenCount` ≤ 20,000 | FR-010, Edge Cases §Conversation length limit |
| Session | Duration ≤ 30 minutes | NFR §Cost Protection |
| RateLimitState | `hourlyCount` ≤ 60 | FR-020 |
| RateLimitState | `dailyCount` ≤ 500 | FR-020 |
| Memory | `expiresAt` = visitor's `lastSeenAt` + 30 days | Spec §Key Entities |
| Greeting | No repeat within 3 sessions per visitor | FR-002, personality bible §5 |
| Visitor | `displayAlias` ≤ 50 chars, optional | Design decision: simple alias |
